# 누에고치 (Nuegochi)

화면 위에 항상 떠 있는, 내가 직접 그린 반려동물을 키우는 안드로이드 앱입니다.
다른 앱을 사용하는 동안에도 화면 위를 자유롭게 돌아다니며, 다마고치처럼 먹이주기·물주기·
놀아주기·똥치우기·씻기기로 돌봐야 합니다. 이름은 마음대로 지을 수 있고, 성장을 모두 마치면
"번데기(고치)"가 되는 것으로 이야기가 끝납니다. (앱 이름 "누에고치"는 누에가 자라 고치가
되는 것에서 따왔습니다.)

## 주요 기능

- **커스텀 스틱맨 반려동물**: 머리 · 몸통 · 팔 · 다리로 이루어진 작은 스틱맨 모양의
  반려동물을 직접 꾸밉니다. 부위를 선택해 색상 팔레트로 칠하고, 팔/다리 길이는
  슬라이더로 자유롭게 조절할 수 있습니다.
- **화면 어디서나 표시**: `SYSTEM_ALERT_WINDOW` 권한을 받아 다른 앱 위에도 항상 보이는
  작은 플로팅 창(오버레이)으로 반려동물을 표시합니다. 평소에는 화면을 자유롭게 스스로
  돌아다니고, 손가락으로 누른 채 움직이면 그 방향으로 따라오며(조이스틱처럼 조종),
  손을 떼는 순간 다시 자유롭게 돌아다니기 시작합니다.
- **터치 상호작용**: 짧게 탭하면 작은 반응 모션(애정 표현)을 보여주고, 손가락으로 꾹
  누르고 있으면(움직이지 않고) 먹이주기 🍚 · 물주기 💧 · 놀아주기 🎾 · 똥치우기 🧹 ·
  씻기기 🛁 관리 메뉴가 뜹니다. 바닥에 놓인 똥을 직접 탭하면 메뉴를 열지 않고 바로
  치워집니다.
- **관절이 있는 자연스러운 움직임**: 팔다리가 어깨/팔꿈치, 엉덩이/무릎처럼 두 마디로
  꺾이며 움직여 걷거나 반응할 때 더 자연스럽게 보입니다. 성장 단계(아기/유년기/청소년기/
  성체)마다 몸을 흔드는 폭과 속도가 달라 각기 다른 성격처럼 느껴집니다.
- **상태에 따라 달라지는 모션**: 배고픔·목마름·행복도·청결도가 뚝 떨어질수록 그 정도에
  비례해 처짐, 헐떡임, 몸서리(청결도가 낮을수록 더 자주·세게) 같은 추가 모션이 자연스럽게
  섞여 나옵니다. 그 외에도 눈 깜빡임, 이동 방향으로 몸을 기울이는 모션, 기력이 매우 낮을 때
  기지개를 켜는 모션 등 다양한 유휴 동작이 함께 재생됩니다.
- **다마고치 스타일 돌봄**: 배고픔 · 목마름 · 행복도 · 청결도 네 가지 상태가 시간이 지나며
  줄어들고, 방치하면 일정 시간마다 똥이 쌓입니다. 각 행동마다 서로 다른 이펙트 애니메이션
  (음식이 떨어지는 효과, 물방울, 하트, 반짝임, 비눗방울 등)이 재생됩니다.
- **성장과 엔딩**: 알 → 아기 → 유년기 → 청소년기 → 성체 → **번데기**의 6단계로 성장합니다.
  성체까지 잘 돌보면 반려동물은 고치를 짓고 조용히 잠드는 것으로 이야기가 끝나며, 이후에는
  새로운 반려동물을 처음부터 다시 만들 수 있습니다.
- **이름 짓기**: 반려동물을 만들 때 이름을 직접 짓고, 나중에 대시보드에서 언제든 이름을
  바꿀 수 있습니다.
- 앱을 완전히 꺼도(다른 앱으로 전환해도) 포그라운드 서비스로 동작하기 때문에 오버레이
  반려동물은 계속 화면 위에 남아 있습니다.

## 화면 구성

| 화면 | 설명 |
| --- | --- |
| `MainActivity` | 반려동물이 없으면 "반려동물 만들기" 화면, 있으면 상태 대시보드(스탯, 성장 게이지, 돌봄 버튼, "화면 위에 항상 표시" 스위치)를 보여줍니다. |
| `PetCreatorActivity` | 부위별 색상과 팔/다리 길이를 정하고 이름을 짓는 스틱맨 커스터마이즈 화면입니다. |
| `PetOverlayService` | `WindowManager` 오버레이로 반려동물을 화면 위에 그리고, 자율적으로 돌아다니며 탭/드래그에 반응하는 포그라운드 서비스입니다. |
| `EndingActivity` | 반려동물이 번데기가 되었을 때 한 번 표시되는 엔딩 화면입니다. |

## 프로젝트 구조

```
app/src/main/java/com/nuegochi/app/
├── data/      // PetStage, PetStats, PetAppearance, BodyPart, PetRepository(저장/성장/스탯 로직), PetEffect
├── render/    // PetView - 스틱맨 반려동물을 그리는 커스텀 뷰
├── overlay/   // PetOverlayService, ActionMenuView, EffectOverlayView, BootReceiver
└── ui/        // MainActivity, PetCreatorActivity, EndingActivity
```

돌봄 상태(배고픔/목마름/행복도/청결도/성장치)는 `PetRepository`가 `SharedPreferences`에
저장하며, 마지막 저장 시각과 현재 시각의 차이만큼 시간 경과에 따른 변화를 계산합니다. 앱과
오버레이 서비스는 이 저장소를 공유하므로 앱을 열든 오버레이로만 보든 항상 같은 반려동물
상태를 보게 됩니다.

## 빌드 및 실행 방법

1. [Android Studio](https://developer.android.com/studio) (Koala 이상 권장)로 이 폴더를
   엽니다. Gradle 동기화가 자동으로 진행됩니다. (minSdk 26 / targetSdk 34, Kotlin 1.9,
   AGP 8.5, Gradle 8.7)
2. 실제 기기 또는 에뮬레이터(API 26 이상)에서 실행합니다.
3. 처음 실행하면 스틱맨 반려동물을 색칠·조절하고 이름을 짓는 화면이 나옵니다.
4. 대시보드에서 "화면 위에 항상 표시하기" 스위치를 켜면 다른 앱 위에 표시할 수 있는 권한
   (다른 앱 위에 표시)을 요청합니다. 허용하면 반려동물이 화면 위에 나타나 돌아다니기
   시작합니다.

> 이 저장소는 Android SDK/에뮬레이터가 없는 환경에서 작성되었기 때문에, 실제 기기/에뮬레이터
> 빌드로 최종 검증을 한 번 해보는 것을 권장합니다.

## 필요한 권한

- `SYSTEM_ALERT_WINDOW` (다른 앱 위에 표시): 화면 어디서나 반려동물을 보여주기 위해 필요합니다.
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE`: 오버레이를 계속 띄워두는 서비스가
  시스템에 의해 종료되지 않도록 합니다.
- `POST_NOTIFICATIONS` (Android 13+): 오버레이가 켜져 있음을 알리는 상시 알림을 위해 사용합니다.
- `RECEIVE_BOOT_COMPLETED`: 기기를 재부팅해도 오버레이가 켜져 있었다면 다시 시작합니다.

## 참고

- 배터리 절약을 위해 반려동물의 상태 갱신은 30초~5초 간격으로만 확인하며, 화면 애니메이션은
  가벼운 2D 벡터/캔버스 드로잉만 사용합니다.
- 반려동물 외형(부위별 색상, 팔/다리 길이)은 이미지가 아니라 `SharedPreferences`에 저장된
  값으로부터 매번 그려집니다.
